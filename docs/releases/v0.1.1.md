# nanoMuse 0.1.1 · Foundation

The first Android build of nanoMuse: [OpenMinis](https://github.com/OpenMinis/OpenMinis) 1.13 with nanoMuse's name, icon and colours, functionally identical to upstream. A version to install for yourself and comment on, not a finished product.

## Added

- **Launcher icon**: the one-stroke N on a white tile — an adaptive icon with a dark skin and an Android 13 themed-icon layer — under the name nanoMuse, in 17 languages.
- **Brand blue** replaces iOS blue and upstream's teal Material scheme; links, thinking, inline code, blockquotes, the send button and your bubbles in the chat use this one hue.
- **About**: the licence, "Based on OpenMinis 1.13" and the Meta trademark note. *Feedback* opens a pre-filled GitHub issue form with version and device; the privacy policy is [docs/privacy.md](https://github.com/nano-muse/nanoMuse/blob/main/docs/privacy.md).
- **Check for updates** in Settings reads this repository's Releases.
- Application id `io.github.nanomuse.app`, so it installs next to OpenMinis. Signed with the project key that every later version uses, so updates install over the previous one without losing data.

## Under the hood

- The app is OpenMinis 1.13 imported with `git subtree` under `android/` (unsquashed, upstream history kept). The iOS half, the iSH submodule and iOS-only scripts are removed; `deps/proot` is a submodule pointing at our fork [nano-muse/proot](https://github.com/nano-muse/proot).
- The Kotlin package stays `com.openminis.app` so upstream releases can be merged; new code lives in `io.github.nanomuse.*`; rebranding is a script (`scripts/rebrand.py`) re-run after every upstream pull.
- The repository is GPL-3.0-or-later ([NOTICE](https://github.com/nano-muse/nanoMuse/blob/main/NOTICE), [THIRD_PARTY_NOTICES.md](https://github.com/nano-muse/nanoMuse/blob/main/THIRD_PARTY_NOTICES.md)); contributions need a DCO sign-off.
- The Python line (`nanomuse/`, `web/`, `demo/`, `site/`) is frozen at tag `pre-openminis`, the base of the web and desktop phases.

## Known issues

- Onboarding offers the subscription sign-ins (OpenRouter, Claude and other OAuth flows) as upstream does. Users in China: *Add provider → OpenAI / compatible API* with your own base URL and key (Bailian, DeepSeek and the like).
- The red panda avatar, the name and identity onboarding, approval scopes and Muse's four tabs are not here yet; they arrive one per version, per the [roadmap](https://github.com/nano-muse/nanoMuse/blob/main/docs/roadmap.md).
- arm64 only; x86 emulators cannot install it.
- 0.1.0 was a debug-signed local test build; uninstall it before installing 0.1.1.

## Install

Download `nanoMuse-0.1.1-arm64.apk` (Android 8.0 or newer, arm64) and install it. Verify: `sha256sum -c nanoMuse-0.1.1-arm64.apk.sha256`.
