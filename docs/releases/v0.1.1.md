# 0.1.1 · alpha · 换皮

nanoMuse 的第一个 Android 版本：[OpenMinis](https://github.com/OpenMinis/OpenMinis) 1.13 换上 nanoMuse 的名字、图标和颜色，功能与上游完全一致。给自己装着用、提意见的版本，不是成品。

## 新增

- 桌面图标是白底蓝色一笔 N（自适应图标，含深色皮肤和 Android 13 主题图标），名字 nanoMuse，17 种语言。
- 品牌蓝替换 iOS 蓝和上游的蓝绿色 Material 配色；聊天里链接、思考、行内代码、引用条、发送键、你的气泡只用这一个色相。
- 关于页：许可证、「基于 OpenMinis 1.13」、与 Meta 无关三行；反馈直接开 GitHub issue 表单，带版本和机型；隐私政策指向 [docs/privacy.md](https://github.com/nano-muse/nanoMuse/blob/main/docs/privacy.md)。
- 设置里的「检查更新」看的是本仓库的 Releases。
- 包名 `io.github.nanomuse.app`，可与 OpenMinis 并存安装；正式签名，之后每个版本覆盖安装不丢数据。

## 已知问题

- 引导页仍有订阅登录（OpenRouter / Claude 等 OAuth）入口，0.1.2 收掉；请直接「添加供应商」填自己的 key（百炼 / DeepSeek 等 OpenAI 兼容端点）。
- 小熊猫头像、名字与身份的引导、国内服务技能、审批范围、Muse 的四个页签都还没有，按 [roadmap](https://github.com/nano-muse/nanoMuse/blob/main/docs/roadmap.md) 一版一个。
- 只有 arm64 包；x86 模拟器装不了。
- 0.1.0 是 debug 签名的本地测试包，装过的要先卸载再装 0.1.1。

## 安装

下载 `nanoMuse-0.1.1-arm64.apk`（Android 8.0+，arm64），安装；校验：`sha256sum -c nanoMuse-0.1.1-arm64.apk.sha256`。
