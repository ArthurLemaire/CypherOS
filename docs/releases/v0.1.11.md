# nanoMuse 0.1.11 · Hatch

A face of its own, and a first conversation the model runs. The default avatar is now a small pale-yellow dragon — drawn and posed with qwen-image-3.0-pro, animated with MiniMax-H3 — bundled with the app, so a fresh install already moves. When it asks what to call you, it is the chat model that reads your answer: say something else and it answers that first and comes back to the name later; the names it proposes for itself are its own, in your language. And the settings now say the simplest way to run all three models: one Alibaba Cloud Model Studio key.

## Added

- **The built-in dragon.** Five stills (at rest, working with headphones and a laptop, waiting with a crystal ball, pleased with a star, sorry with a sweat drop) and four 4-second looping clips ship in the APK, about 1.2 MB in all. The header, the avatar page and notifications use them; your own face, when you make one, replaces them the same way as before. *Back to the built-in face* in the avatar menu returns to it.
- **The first conversation is the model's.** "What should I call you?" is no longer matched with patterns. The chat model decides what your reply meant: a name or a nickname — it confirms it and asks what you would like to call it; "nothing in particular" — fine; anything else — it helps with that first, in full, and brings the question back. The two names it proposes for itself are made up on the spot, Chinese when you write Chinese (in the spirit of 豆丁 or 小满), English otherwise (Pip, Wren, …), never the name of an existing assistant. Type a name, "call you X" or "the first one" and it takes it; ask something else and the chooser simply stays.
- **One key, three models.** *Settings → Image & video models* and the welcome screen now say it: one Model Studio key covers the chat model, `qwen-image-3.0-pro` and `MiniMax/MiniMax-H3`. Each model is still chosen on its own, so any of them can come from a different provider on a different key. With a Model Studio image provider set and no video choice made, the video model follows it; choosing *No video model* is remembered.

## Changed

- The suggested Model Studio image model is `qwen-image-3.0-pro`, which both draws the candidates and poses the chosen one; the request format follows the 3.x models.
- The image and video rows on the media page read `model · provider`.
- The fallback name pools drop names other assistants use.
- versionCode 12; installs over 0.1.10 without losing data.

## Known issues

- arm64 only; for an x86 emulator, build a test APK yourself with `-Pnm.abi=x86_64`.
- The first conversation depends on the chat model following the block format; a model that ignores it leaves the chooser waiting — type the name and it is taken on the next reply.
- Clips for a custom face are made one after another and each takes one to a few minutes on the provider's side; leaving the app in the middle stops the run, and *Redo* on the clips row starts it again.

## Install

Download `nanoMuse-0.1.11-arm64.apk` (Android 8.0 or newer, arm64) and install it over the previous version — same signing key, your data is kept. Verify: `sha256sum -c nanoMuse-0.1.11-arm64.apk.sha256`.

一张自己的脸，和一段由模型来接的第一次对话。默认形象换成了一只奶黄色的小龙——用 qwen-image-3.0-pro 画出并摆好姿势、用 MiniMax-H3 做成动态——直接内置在应用里，刚装上就会动。它问「该怎么称呼你」时，读你回答的是对话模型本身：你说了别的，它先答别的，稍后再把名字的事接回来；它给自己提的名字是当场想的，跟着你的语言走。设置里也把三个模型最省事的跑法说清楚了：一把阿里云百炼的 key。

### 新增

- **内置小龙。** 五张静态图（待机、戴耳机敲电脑、抱着水晶球等你、举着星星开心、冒汗抱歉）加四段 4 秒的循环短片一起装进 APK，共约 1.2 MB。页头、形象页和通知都用它；你自己做的脸照旧替换掉它。形象菜单里的「换回内置形象」可以换回来。
- **第一次对话交给模型。** 「该怎么称呼你」不再靠规则匹配。对话模型自己判断你的回复是什么意思：是名字或昵称——确认一下，再问你想叫它什么；「随便」——也行；别的话——先把那件事答完，再把问题带回来。它给自己提的两个名字是当场想的，你写中文就是中文名（豆丁、小满这一路），写英文就是英文名（Pip、Wren……），不会撞上已有的助手。打一个名字、「就叫你 X」或「第一个」它就认了；问别的，选择卡留着不动。
- **一把 key，三个模型。** 「设置 → 图像与视频模型」和欢迎页现在都写明：一把百炼的 key 就能覆盖对话模型、`qwen-image-3.0-pro` 和 `MiniMax/MiniMax-H3`。每个模型仍然单独选，所以任何一个都可以来自另一个平台、另一把 key。图像模型设在百炼上、视频没单独选时，视频模型跟着它走；选了「不用视频模型」会记住。

### 变更

- 百炼推荐的图像模型改为 `qwen-image-3.0-pro`，画候选和摆姿势都用它；请求格式按 3.x 系列。
- 图像和视频那两行的状态改为「模型 · 服务商」。
- 兜底名字池去掉了别的助手在用的名字。
- versionCode 12；覆盖安装 0.1.10 不丢数据。

### 已知问题

- 只有 arm64 包；x86 模拟器请自行用 `-Pnm.abi=x86_64` 打测试包。
- 第一次对话依赖对话模型按格式输出；模型不照做时选择卡会一直等着——直接打出名字，下一轮就会认。
- 自定义形象的短片一段接一段生成，每段在服务商那边要一到几分钟；中途离开应用会中断，短片那一行的「重做」可以重来。

### 安装

下载 `nanoMuse-0.1.11-arm64.apk`（Android 8.0+，arm64），覆盖安装，同一把签名，数据保留；校验：`sha256sum -c nanoMuse-0.1.11-arm64.apk.sha256`。
