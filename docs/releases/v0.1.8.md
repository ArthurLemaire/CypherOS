# nanoMuse 0.1.8 · Polish

The shell, brought level with Muse's. Nothing changed underneath — same agent, same providers, same settings — but the type, the home composer, the header and every settings page now follow Muse's own screens instead of OpenMinis' iOS-style chrome. Compared side by side with Muse on the same phone, the differences left are the ones we mean: an open-source app with your own model, no invite codes, no plan.

## Changed

- **Type.** Muse renders in the phone's system face (MiSans on Xiaomi, Roboto elsewhere) — that is where its "premium" look comes from, so nothing is bundled. What changed is the scale: zero letter-spacing, 16/24 body text, 13 and 14 for secondary lines, SemiBold titles, 17 for page titles. Your text-size setting still applies.
- **Home composer.** One row on a flat grey capsule, the way Muse's is: a bare "+", *Message*, a bare mic. A blue send arrow takes the mic's place once there is something to send, and the stop button while the agent works. The "/" commands live under "+" → *Commands*. Voice mode, recording and message editing keep OpenMinis' two-row card.
- **Header.** Only the agent's name under the face. The model rows (group, provider · model) are off by default; *Settings → Appearance → Home → Show the model under the name* brings them back, live. With them off, ••• → *Model* opens the picker.
- **Replies.** Grey bubbles, one per paragraph, no "✦ name" above each turn — the face in the header says who is talking. Code, tables and HTML stay full-width.
- **Settings.** Muse's page: a round back disc, a centred title, white cards on the grey canvas, one ink glyph + label + chevron per row, no section headers. The main page opens with your model (default group, provider · model, *Change*) where Muse has its plan, then providers and usage; the agent — Soul, Avatar, Memory, System files, Skills, MCP, Environment variables; the phone — Permissions, Background, Storage, Shared folders, Mounted folders, Backup; the app — Appearance, Logs; About, Privacy, Feedback; the version at the foot. Every sub-page has the same bar, bare glyphs instead of coloured tiles, sentence-case labels and Muse's radio rings.
- The chat screenshot in the README is retaken on this build.
- versionCode 9; installs over 0.1.7 without losing data.

## Kept on purpose

- Every OpenMinis feature and setting. The two-row composer for voice, recording and editing. The status line under the name ("Needs approval", "Working…"), the naming card of the first conversation, the approval cards.

## Known issues

- arm64 only; for an x86 emulator, build a test APK yourself with `-Pnm.abi=x86_64`.

## Install

Download `nanoMuse-0.1.8-arm64.apk` (Android 8.0 or newer, arm64) and install it over the previous version — same signing key, your data is kept. Verify: `sha256sum -c nanoMuse-0.1.8-arm64.apk.sha256`.

把壳子对齐到 Muse。底下没动——同样的智能体、同样的服务商、同样的设置——但字体排印、首页输入框、页头和每一个设置页现在照着 Muse 自己的界面来，而不是 OpenMinis 的 iOS 风格。和同一部手机上的 Muse 并排看，剩下的差别都是有意的：开源、用你自己的模型、没有邀请码、没有套餐。

### 变更

- **字体。** Muse 用的就是手机的系统字体（小米上是 MiSans，其它机器是 Roboto）——它的「高级感」来自这里，所以我们不内置字体。改的是字号体系：字距归零，正文 16/24，次要文字 13 和 14，标题 SemiBold，页标题 17。你的字号设置仍然有效。
- **首页输入框。** 一行、扁平灰色胶囊，和 Muse 一样：裸的「+」、「消息」、裸的麦克风。有内容可发时蓝色箭头替掉麦克风，智能体工作时是停止按钮。「/」命令收进「+」→「命令」。语音模式、录音和编辑消息仍用 OpenMinis 的两行卡。
- **页头。** 脸下面只有名字。模型两行（模型组、服务商 · 模型）默认不显示；「设置 → 外观 → 首页 → 在名字下方显示模型」可以随时打开，即时生效。关闭时 ••• → 「模型」打开选择器。
- **回复。** 灰色气泡，一段一个，每轮上方不再有「✦ 名字」——页头的脸已经说明谁在说话。代码、表格和 HTML 保持全宽。
- **设置。** Muse 的页面：圆形返回按钮、居中标题、灰底白卡、每行一个墨色图标 + 文字 + 箭头，没有分组标题。主页最上面是你的模型（默认组、服务商 · 模型、「更换」），对应 Muse 的套餐卡，然后是服务商和用量；智能体——灵魂、形象、记忆、系统文件、技能、MCP、环境变量；手机——权限、后台、存储、共享文件夹、挂载文件夹、备份；App——外观、日志；关于、隐私、反馈；页脚是版本号。每个子页同样的栏、裸图标替代彩色方块、句式分组标签、Muse 的单选圆环。
