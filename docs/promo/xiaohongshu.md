## 正文

```
nanoMuse 是一个完全开源的、Muse 式的个人智能体，现在是一个 Android App。

Meta 的 Muse 给出了一种新的样子：不是一个聊天框，而是一个有名字、有脸的智能体，替你办事，App 关着也在后台干活，记得你，遇到删不回来的事先问你。我们把这个样子做成了开源软件，跑在你自己的手机上。

它能做什么
· 手机里装着一套 Linux、一个浏览器，还有 MCP 和技能。说一句，它去办；每一步都是一张能点开看的卡片。
· 没有接口的 App 也能操作。打开「动手操作屏幕」，它看一眼截图、做一步、再看一眼，像你一样点。技能、命令行、浏览器能办的先用它们，屏幕排在最后。默认关闭。
· 手机上说一句，电脑上干完。电脑上跑一个 Python 文件，App 里填六位配对码，跑命令、拿文件、开网页都行，结果和审批都回到手机上。
· 每天早上一份写给你的动态；目标定下来，它到点就查进度。
· 删除、发送、付款之前一定先问你。密码和验证码永远你自己输。

它不做什么
· 没有服务器，不用注册账号。聊天内容只发给你自己配的模型，文件和记忆都留在手机里。
· 不绑定模型。任何 OpenAI 兼容接口都行；一把阿里云百炼的 key 就能把对话、图像、视频三个模型一起配好。
· 不替你输密码，不替你点付款。

你需要什么
一台 Android 8.0 以上的 64 位手机，一个模型的 key。装好之后它先问你怎么称呼，再给自己起名字；想换脸，一句话描述，你的图像模型画四张给你挑。

整个仓库 GPL-3.0-or-later，基于 OpenMinis 1.13 修改，每一版都从 tag 构建、手动安装。现在是 0.1.15，一个小版本一个 APK，每一版的说明都在仓库里。

搜 nanomuse.cn。有问题评论区说，我们都看。

nanoMuse 是独立的社区项目，与 Meta 无关；Muse 是 Meta 的商标。
```

## 置顶评论

发出后马上评论，然后置顶：

```
下载：搜 nanomuse.cn，首页就是最新版；GitHub 上搜 nanoMuse 也能找到。

几个常见问题：
① 要什么模型？任何 OpenAI 兼容接口，加你自己的 key。想让它操作屏幕，对话模型得能看图，比如 qwen-vl 系列。
② 花钱吗？App 免费、开源。模型按你自己的 key 计费：聊天很便宜；操作屏幕时每一步发一张截图，选小一点的视觉模型更省。
③ 为什么要无障碍和悬浮窗权限？无障碍只用来截图和做手势，不读屏幕内容；悬浮窗用来显示带「停止」的胶囊。两个都只在你打开「动手操作屏幕」之后才需要。
④ 有 iOS 吗？还没有。接下来是桌面 App、iOS、部署在自己机器上的网页版。
⑤ 让 AI 操作第三方 App 有风险吗？有的 App 对自动操作敏感，建议先用不重要的账号试。付款、发送、删除前它都会先问你。
```
